# XAdSkip 0.3.1

包名仍为 `app.xadskip.android`，versionCode 为 4。使用与 0.3.0 相同的发布签名，可以覆盖升级并保留应用数据；不会重置已有订阅、规则或授权。

## 授权引导

- “开启辅助”优先打开系统允许的最具体无障碍入口。详情页不可用或不允许普通应用访问时，自动回退到无障碍列表，并尽力定位本应用条目。
- “无法开启？”可直接打开 XAdSkip 自己的应用信息页，无需自行从设置中寻找应用。
- 进入应用信息前说明所需操作：用户自行选择“允许受限设置”，返回应用后继续无障碍授权。返回流程最多衔接一次；已明确仍被限制时保留说明，不反复跳转。
- 系统页面返回不等于授权成功，应用以真实的无障碍服务启用状态判断结果。未知的受限状态不会显示成已解除。
- 重复点击不会叠加多个授权流程；取消流程不会自动授予权限。

## Android 系统边界

普通应用无法自行解除受限设置或静默开启自身无障碍服务。Android 17 的无障碍详情入口受系统/安装器权限保护，所以部分手机仍需在无障碍列表中点选 XAdSkip。“定位本应用”所用设置页提示参数也可能被厂商忽略。

解除受限设置的确认仍需在应用信息页由用户完成，可能包含菜单、身份验证或系统提示；应用无法保证每个品牌都只有一次点击。不使用 Root、ADB 授权、安装来源伪装或受保护的 ECM 接口来改变这一限制。

## 构建

沿用 0.3.0 的构建和签名流程，仅构建 `gkd` 渠道。发布包必须关闭调试并使用项目原有发布签名，不能用调试签名替代。

模拟器检查不能替代小米、华为、OPPO、vivo 等实际机型验证。
