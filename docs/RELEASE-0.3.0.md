# XAdSkip 0.3.0

本版面向公益助老场景，保留 GKD 与各规则来源的许可证及署名。

## 使用变化

- 新安装首次启动自动离线准备并启用甘霖 v71；保留其类别和规则组各自的默认开关，不自动开启所有规则。
- 已有订阅和之后关闭、删除、修改的选择不被覆盖；内置订阅不进行网络更新。
- 首页显示准备状态、辅助状态及开启、暂停或继续按钮；高级功能收进“更多设置”。
- Android 10 及以上优先尝试打开本应用的无障碍详情页，打开失败或旧系统回退到通用无障碍设置；权限仍由用户在安卓系统页面亲自确认。不同系统的受限设置与后台限制可能需要额外操作。
- 增加本项目的首次说明、应用隐私说明及反馈邮箱，移除指向上游的自动 GitHub 上传和捐赠引导；本地导出与开源致谢保留。

## 包名与迁移

正式版为 `app.xadskip.android`，版本名 `0.3.0`，版本号 `3`。
旧开发包 `app.xadskip.android.debug` 是另一个应用，不能覆盖升级；用户需另行安装并确认权限，旧配置不自动迁移。

## 构建与签名

使用 README 中固定的 JDK 21、SDK 37.0、Build Tools 37.0.0 与仓库 Gradle Wrapper，仅构建 `gkd` 渠道：

```sh
sh ./gradlew :gkd-app:assembleGkdRelease :gkd-app:testGkdDebugUnitTest --no-daemon
```

从源码 ZIP 构建时，先在解压目录 `git init` 并提交该源码快照，供构建脚本读取提交元数据。
正式构建关闭调试、压缩代码和资源；版本名不追加开发提交后缀。
单元测试使用项目已配置的 `gkdDebug` 测试变体；公开下载的 APK 仅取 `gkdRelease` 产物。
未提供签名参数时正式产物为未签名 APK，绝不回退到 debug 密钥。
可通过 `GKD_STORE_FILE`、`GKD_STORE_PASSWORD`、`GKD_KEY_ALIAS`、`GKD_KEY_PASSWORD` 配置自己的签名，或对未签名 APK 使用 Android `apksigner` 签名。

签名私钥和口令必须留在源码目录之外，不随源码包或网站公开；后续同包名更新必须继续使用同一签名。

## 验证边界

构建、单元测试及安装包完整性结果应以本次发布记录为准。静态检查和编译成功不能代替实机验证；不同机型和应用版本仍可能导致规则失效或误触，用户可随时暂停。
