# 银杏助手 0.3.4

版本号 `0.3.4`，versionCode `7`。正式包名 `app.xadskip.android` 和正式签名延续，覆盖升级保留用户数据。下载文件名为 `XAdSkip-0.3.4.apk`。

## 本次变化

- 更名为银杏助手，使用银杏叶图标；首次引导说明必须由用户在系统中开启无障碍。
- 三套来源合并为统一规则库。新安装默认准备；升级迁移保留原有开关和排除设置，无法确认的自定义内容保留原状。
- 进入应用自动检查签名规则清单；只有来源、签名、大小、哈希、版本和稳定标识检查通过才应用，失败沿用现有规则。
- 进入应用检查软件版本，首页显示可安装的新版本；下载和系统安装仍由用户确认。
- 增加支持应用查询，展示广告规则与当前启用数量。收录不等于实机验证通过；不具备专用广告规则的条目明确说明。
- 触发记录保存当时的应用与规则名称、实际操作及位置。成功操作记录不依赖打开日志页面；写入异常会显示提示。
- 默认关闭可选状态通知，提供后台设置说明。Android 要求的服务通知保留，无法保证应用被系统或用户强制停止后继续运行。
- 官网和应用接入图片/录屏反馈；官网增加文字、图片、视频许愿池。原文和附件私有，开发者审核整理后公开文字与进度，完成显示 ✓。

## 规则范围

统一规则版本 1：774 个应用配置、2343 个应用组、12 个全局组。其中 519 个应用具有广告类别规则，255 个只有其他用途或待验证转换规则。默认启用 105 个应用中的 106 个广告组及 1 个通用开屏组。李跳跳转换产生的 692 个草稿保持关闭，避免未经验证的自动点击。

保留来源、作者、固定源码和许可证，详见 `rules/UNIFIED_RULES.md`、`rules/COMMUNITY_SOURCES.md`。

## 已完成的针对性检查

发布准备期间，Android 正式构建、131 项应用单元测试和 17 项数据库 JVM 测试通过；反馈/许愿池后端 32 项 HTTP/CLI 测试、前端 17 项测试通过。统一规则生成与兼容性检查通过。公开上传、签名 APK 哈希、安装设备与公网检查结果记录在仓库外的发布档案中，不能仅凭本文件认定已经上线或完成真机验证。

当前未复现用户真机上“打开日志开关前没有记录”的现象；源码中没有触发记录总开关。本版完善持久化和诊断，并用独立回归检查记录不依赖先打开查询页面。后续真机反馈仍用于排查特定机型行为。

## 发布与回退

日常使用 `develop`，对应版本保留 `release/0.3.4` 和 `v0.3.4`。旧 APK、源码、页面、更新清单与云端配置备份保留。官网和版本清单可回退到上一版；Android 覆盖降级受系统版本码限制，不能承诺直接保留数据降级。

许愿池采用追加数据表。产生愿望后，不得将反馈服务回退到不认识愿望附件的旧程序；静态页可以单独回退，服务需保留支持愿望的版本。详情见 `services/feedback/README.md`。反馈数据、发布私钥和运行凭据不进入 Git 或公开源码包。
