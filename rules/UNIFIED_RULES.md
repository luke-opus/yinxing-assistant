# 银杏助手统一规则

本次输入是已固定的甘霖 v72、奥怪 v89 和李跳跳迁移草稿 v1。它们是当前仓库的快照，不把合并版本号称为上游的新版本，也不把收录应用数量视作实际生效证明。

## 生成与来源

运行 `python3 tools/build_unified_rules.py --version N`；依赖与现有转换器相同的 `json5`。`--check` 只核对输出。先运行 `tools/test_build_unified_rules.py`，再运行应用的规则解析、迁移和签名校验测试。Android 检查使用 `gkd` 渠道。

输出 `assets/xadskip/unified/rules.json` 为 GKD 可读订阅，固定订阅 ID 为 `2026111801`，名称为“银杏助手统一规则”。额外 `xadskip` 字段记录来源的提交、许可、原始 ID 与稳定组映射；`catalog.json` 提供包名、名称、广告规则组数量、默认启用数量与来源列表。`rules/unified-report.json` 记录去重和冲突；`rules/unified-identities.json` 是持久身份账本，必须随源码保留，不能在下一次生成前清空。

李跳跳原始数据是包名哈希与专用规则语法，不能作为 GKD 订阅直接解析。这里仅合入现有 `convert_ltt.py` 明确转换成功的草稿，所有草稿保持关闭；不猜测坐标、重复动作或其他未支持语义。其余内容仍见 `conversion-report.json`。

## 去重与冲突

同一应用作用域内，只有完整组行为一致，才折叠为一个组。比较包含选择器、动作、页面/版本限制、时序、次数以及依赖；不以组名或截图 URL 决定等价。有跨组作用域依赖的组不折叠。组的 `scopeKeys` 重映射，规则内部 `key`、`preKeys`、次数及冷却引用原样保留。

完全相同的行为保留所有来源归属，默认关闭的来源优先。跨来源相同匹配条件但行为不等价的组保留为关闭候选。多个全局开屏回退组只默认开启首个，其他候选关闭。其他不同选择器仍可能在实际界面重叠，此静态规则合并不能证明完全消除所有运行时重叠。

各来源 `disableIfAppGroupMatch` 的排除范围按原来源的应用组固化，防止合并后其他来源的同名前缀意外扩大排除范围。非广告组不默认开启；原来源类别默认值已落到各组，统一类别不额外设置 `enable=true` 来覆盖原作者关闭的组。

旧别名即使主来源删除，也继续使用同一个稳定组 ID。已经合并的别名未来分裂为不同动作时，生成器会拒绝发布，要求维护者设计显式迁移。已存在的两个不同组也不会在后续版本静默折叠成一个新身份。客户端再次检查共同来源映射不能换 key。

## 旧用户迁移

首次迁移先与已知原始快照对比，检测到手工改写或未知版本则保留原库。正常迁移复制组有效开关、应用禁用及排除；相同目标合并时，显式禁用和排除优先。原类别开关在组层落地，保留组级覆盖优先于类别的语义。

未安装的来源不自动带入活动组。原先单独启用的次级全局回退在没有活动主回退时继续使用，并保留排除；不会额外开启另一来源的全局组来绕过旧排除。原订阅仅关闭归档，文件、用户配置、历史日志均不删除。独立本地订阅不参与迁移。一次性迁移标志防止用户删除统一库后又被自动恢复。

## 签名发布与回退

生成器输出待签名的 `rules/unified-manifest-payload.json`，其中包含格式版本、固定订阅 ID、递增发布版本、最低应用版本、固定 HTTPS 下载路径、字节数、SHA-256 及对应源码链接。`--min-app-version-code` 应指定首次支持该格式的正式 APK 版本号。

维护者用仓库外保存的 RSA 发布私钥，对 payload 文件的**原始字节**进行 `SHA256withRSA` 签名。发布包为 `{ "algorithm": "SHA256withRSA", "payload": "原始字节的Base64", "signature": "签名的Base64" }`。公钥 DER 随 APK 发布；私钥不得进入仓库、APK、日志或源码包。先上传版本目录的 `rules.json` 和对应 `source.zip`，最后更新 `https://xadskip.com/rules/stable/manifest.json`。

客户端在明确的应用进入事件中异步检查，合并一分钟内的重复进入。未启用自动更新、用户删库、自定义内容不匹配、签名/哈希/格式/最低版本/组身份/选择器校验失败时，不替换当前库。成功持久化后更新订阅 snapshot，沿用现有引擎的数据流；不重置用户开关或排除，也不要求后台推送 SDK。

网络源只接受 `xadskip.com` 固定 HTTPS 版本路径，不跟随重定向。缓存保留经过确认的当前与上一个来源，作为用户改写检查和来源追溯。回退必须重新发布**更大的发布版本号**，内容可恢复到此前可用版本；客户端不接受普通降版。首次安装和迁移时也保存可信内置基线，防止下一次 APK 升级缺失旧基线。
